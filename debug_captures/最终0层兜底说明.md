# 最终0层兜底

默认自主模式完成既定路线后，剩余未确认塔逐个进入最终观察：

1. 先调用现有安全规划器寻找需要移动的观察点。
2. 无可达靠近点时，允许当前位置或其他安全姿态作为补偿观测，不再强制中距。
3. 执行安全移动/转向/俯仰，到位后经过原有停稳检查；有正常识别结果即优先采用。
4. 连续有效观察至少2秒、至少6次不同时间更新，仍未确认时输出0层，标记为“兜底推定，非识别确认”。每个剩余目标不再无限追加观察。

移动未到位、无画面、未停稳、有效观察间断超过0.5秒，不计为兜底观察完成。仍遵守现有定位输入有效性与安全行驶检查。不直接控制硬件。若连安全补偿姿态都没有，则保持blocked等待，不把未发生的观察写为0。

保存记录新增 `fallback_zero`（各塔推定原因）和 `final_fallback`，history使用 `fallback_approach`、`fallback_compensation`、`fallback_zero` 区分事件；终端列出兜底塔号。已有正常锁定值不被覆盖。原地逐档扫描模式不增加该最终阶段，默认路线自主模式启用。

回归重点：既定路线结束才进入最终阶段、靠近失败转补偿、补偿后未知输出0、采样/停稳/画面不足不得填0、已有正常结果不覆盖、输出明确标记推定。
