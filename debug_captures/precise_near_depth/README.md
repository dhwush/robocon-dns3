# 近处层高误差≤3cm时深度优先

修改位置：`classify.py` 的近处深度主判。适用既有0.3–3m有效深度范围，不引入历史结果保持，不用上一帧掩盖当前反证。

## 行为

已有实体归属、有效点数、盒宽和非上下出画检查通过，实测最高有效高度距一层/两层标准高度不超过3cm时，优先输出该深度层数。局部顶边、RGB轮廓和RGB补高不能推翻已取得空间支撑的精确深度档。

保留明确上层实测占用、独立顶块优先、实体归属与尺寸保护。允许远离盒顶的部分空域缺测；紧邻候选顶高的两档采样仍需至少13处有效观测、80%支持穿过塔位。否则继续原有识别流程，防止两层上半部全部缺测后恰好剩下35cm被错误认作一层。

`precise_depth`诊断记录实测高度、档位误差、3cm阈值、空域证据及是否采用。原有`depth_top_check`仍保留，便于比较局部顶边失败但精确层高优先生效的情况。

## 验证

`tests/test_precise_near_depth.py`覆盖一/两层、误差正负方向、超3cm拒绝、RGB高横线冲突、远处背景部分缺测、真实两层上半部深度缺失，以及顶边附近4像素混合近回波导致局部顶边检查失败时仍正确输出。

此前录像场景的真实RGB与受控深度测试`tests/test_video_170811.py`一并回归。19:17录像没有原始深度，不能把本次合成深度测试当作5:00真实RGB-D重放；现场仍需核对新增`precise_depth`诊断。
