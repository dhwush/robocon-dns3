## 实现

5号：新增`_cap_pair_masks`。在原红蓝联合闭合区域内，只有两种颜色各自均有占比至少80%的块状主核心、其余单块至多为主核心10%时才移除小碎片。归属与读色共用该提取过程；两个相当大小的色块保留，继续执行原多候选、块状和上下顺序校验。

6号：局部盒面深度原始归属比例未达70%时，先要求至少30个本塔点覆盖候选70%以上横向列，再允许排除比本塔95%分位距离远至少max(12cm,距离3%)的背景回波，重新核验70%归属。前景和距离相近的异面仍保留为反证；无本塔支撑不能靠剔除背景通过。上方实测占用仍拒绝，缺测仍不当空域。新增支撑点、原始/分离后比例、背景点数和候选拒绝原因诊断。
