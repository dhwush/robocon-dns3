## 复现与限制

在仓库根目录运行：

```bash
PYTHONDONTWRITEBYTECODE=1 python debug_captures/rgb_validation_20261116/replay.py
```

脚本读取原视频指定时间，裁切原图区域 `(352,188)-(2912,1628)` 并缩放到1280×720，使用 `config/intrinsics.yaml`。位姿从录屏文字人工抄录：

- 00:29：x=-0.010m，y=0.021m，yaw=-0.5°，pitch=-1°。
- 02:13：x=-0.248m，y=0.191m，yaw=-46.9°，pitch=-1°。
- 02:15：x=-0.243m，y=0.195m，yaw=-46.9°，pitch=0°。

横滚统一假设0°。这些不是与视频逐像素同步的原始位姿。录像没有原始米制深度，本次传入depth=None，没有使用伪彩深度图冒充米制深度。录屏叠字和轮廓遮住的像素不能恢复，现场原始RGB仍需复验。

01:35另取d诊断中的原图面板，按画面中2号搜索区域人工设置ROI，仅验证红蓝配对检测器：右上出画的顶块得到“红”。`cap95_manual_roi.json`保存此项结果；它不属于上述完整inspect_frame回放，也不声称验证了自动塔位归属。这里的位姿为占位值，仅供诊断顶高，不参与配对通过条件。
