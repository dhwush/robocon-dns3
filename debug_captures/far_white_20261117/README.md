# 2026-11-17 远处白盒回归

修改前 Git 快照：`89e0b6b`。

## 样本与边界

从两段录像提取 6 个真实 RGB 画面，以录屏显示的位置、yaw、pitch 复算 3 号塔：

- `13-31-34.mkv`：1:19、1:21、1:22。
- `13-34-26.mkv`：0:30、0:40、1:00。

原始截图仅裁出相机画面并缩放至相机内参分辨率，保留录屏中的叠加框线。位姿来自界面读数，有显示精度误差。样本元数据见 `cases.json`。

录像没有原始深度阵列，因此每帧分别运行 RGB-only、全缺测、8m 背景回波、2m 连续前景四种受控输入。后面三种是合成深度，用于检验融合分支，不能代表现场 RGB-D 重放，也不能证明录像每一帧的准确率。

## 修改

1. 远处真实顶边、侧边和连续白盒面已核验时，缺测或远背景深度不再否决 RGB；盒面内连续、深度一致的近前景仍否决。近处可靠深度主判保持。
2. 有可靠 RGB 候选时，在实际候选盒面检查前景覆盖，避免搜索区下方桌面、线缆连带否决可见盒顶；上层实体占用保护保留。
3. 局部顶边候选先在同层中保留完整相对盒高的定位优势，再在不同层之间比较实际盒面支撑分数；相对单盒高度不能跨层无条件抢占。保留旧的近处冲突处理，避免把旧录像中的单层改判两层。
4. 停稳使用最近 1 秒的采样窗口，进入阈值 2.5cm/1°，已停稳后的退出阈值 4cm/1.5°；仍要求至少 3 次有效采样和 0.6 秒，重复时间戳不累计。界面显示具体阻塞原因。

## 复现

在仓库根目录运行：

```bash
PYTHONDONTWRITEBYTECODE=1 python debug_captures/far_white_20261117/replay.py
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1 python -m pytest -q tests/test_far_white_video_20261117.py tests/test_far_rgb_fusion.py tests/test_camera_stability.py
```

`results.json` 包含快照版本与修改版本逐帧的结论、识别框和候选诊断。测试同时核对层数和真实顶边位置，连续前景输入必须拒绝输出。

修改前全量基线：537 通过、1 失败。已有失败为 `test_lateral_request_selects_reachable_view_with_real_parallax`，路径动作得到 `stuck` 而非 `move`，与本次白盒融合无关。最终全量输出见 `tests_after.txt`。

最终结果：579 通过、1 个上述既有路径失败；42 项录像与融合针对性检查全部通过。六帧 × 四种输入的逐帧对比为 24/24 满足预期。
